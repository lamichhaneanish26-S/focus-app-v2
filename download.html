Windows

Windows 10 and 11

⬇ Download for Windows
How to install
  1. Open Focus-Setup.exe from your Downloads.
  2. If you see “Windows protected your PC”, click More info, then Run anyway. This shows for apps from small developers.
  3. Follow the steps. Focus appears on your desktop and Start menu.
💻

Mac

Intel and Apple-chip Macs

⬇ Download for Mac
How to install
  1. Open Focus.dmg and drag Focus into Applications.
  2. Open Focus. If your Mac says it can't check the app, open System Settings → Privacy & Security, scroll down and click Open Anyway.
  3. You only need to do this the first time.
🤖

Android

Phones and tablets

⬇ Download for Android
How to install
  1. Tap Focus.apk when the download finishes.
  2. If asked, allow your browser to install unknown apps, then go back.
  3. Tap Install. Focus appears with your other apps.

Prefer not to download? In Chrome, tap ⋮ → Install app on the Focus website.

📱

iPhone & iPad

Installs from Safari, no download needed

Open Focus in Safari
How to install
  1. Open the Focus website in Safari.
  2. Tap the Share button (square with an arrow).
  3. Tap Add to Home Screen, then Add.

Apple only allows app files through the App Store, so iPhone and iPad install Focus this way.

🐧

Chromebook & Linux

Install from Chrome, or download for Linux

⬇ Download for Linux
How to install
  1. Chromebook: open the Focus website and click the install icon in the address bar.
  2. Linux: download Focus.AppImage, right-click → Properties → allow running as a program, then open it.
